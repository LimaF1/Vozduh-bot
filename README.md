# Vozduh-bot

Flask-версия бота магазина «Воздух». Приём заказов на шары работает в личном чате.

Для запуска установите зависимости командой `python -m pip install -r requirements.txt`. Запустите WSGI-приложение `main:app` на хостинге с HTTPS и постоянным диском. Для локальной проверки используйте `python main.py`.

| Переменная | Значение |
| --- | --- |
| TELEGRAM_BOT_TOKEN | Токен существующего бота, хранить в секретах хостинга |
| TELEGRAM_WEBHOOK_SECRET | Секрет для заголовка Telegram, обязательный для бронирования |
| BOOKING_OWNER_ID | Числовой ID владельца. Владелец должен первым открыть чат с ботом |
| BOOKING_PRICE | Реальная цена или текст о принципе расчёта |
| BOOKING_DATES | Свободные даты через запятую в формате YYYY-MM-DD |
| BOOKING_DATABASE | Путь к SQLite на постоянном диске |

Telegram webhook принимает запросы на `/webhook`. При переключении на этот сервер задайте тот же `secret_token` в Telegram. У одного бота один webhook, поэтому переключение заменяет обработчик, который уже работает. Эта версия Flask не запускается на Cloudflare Workers без переноса.

Покупатель выбирает дату и отправляет имя, контакт и описание заказа. До подтверждения дата доступна другим покупателям. Одновременные подтверждения одной даты исключает SQLite. Прошедшие даты рассчитываются по Москве. Для обработки используйте один экземпляр приложения с постоянным хранилищем.
